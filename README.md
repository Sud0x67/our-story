## 检查入口

`?scene=river&at=20&paused` 查看坐稳聊天；`?scene=mountain&at=6&paused` 查看观景台并排停留；`?scene=mountain&at=19&paused` 查看牵手上山；`?scene=stars&at=13&paused` 查看银河；`?scene=ring&at=19&paused` 等待点击开盒。纸雕版在这些参数前加 `look=paper&`。

默认按点击或滑动推进故事，每幕都会等待。点击触发当前动作，再点一次转场；左滑/上滑（或滚轮向下、右方向键）完成动作并接着转场，右滑/下滑（或滚轮向上、左方向键）返回上一幕。双指或鼠标右键拖动观察场景，单指不会再与相机拖动冲突。隐藏操作：空格暂停，Enter 等同点击，T 字幕，M 音乐，F 全屏，Home/R 重播，End 直接进入等待开盒。录制预览可用 `?autoplay` 保留连续播放，默认没有自动连播。

## 无底座场景与交互节奏（V0.7.0）

所有 19 幕移除展示底座，包括室内厚地块和戒指圆形展台。连续地面延伸到相机视野以外，河道、道路、湖面、海面与栈道扩展；远树、街屋、山体和雾补足环境。地面固定，不再整体上下悬浮。驾驶道路已对齐车辆行驶方向。

每幕分为进入、等待、动作、停留、转场。第一次轻点触发动作，第二次轻点转场；动作进行中再点，会在动作结束后接着转场，避免中断坐下、牵手等动作。左/上滑将这两步连起来；返回使用右/下滑。滚轮有阈值和惯性防抖，双指操作不会误触。最后开盒只接受明确点击或 Enter，滑动不会开启。

场景内按回忆分别出现轻微声波、酒杯微光、热气、水纹、流星、落叶、风线或翻牌反馈，不新增操作面板。日期、人物服装、原始字幕及已移除的背后拥抱细节保持当前确认结果。详见 `docs/story-script.md` 的逐幕交互说明。

构建产物：`dist/` 与 `our-story-v0.7.0-static.zip`。本次修改只在主开发目录；`our-story2` 原版备份和 `our-story3` 二维样片保留。源码修改前快照为 `.work/source-before-v0.7.zip`。
