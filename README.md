## 检查入口

`?scene=river&at=20&paused` 查看坐稳聊天；`?scene=mountain&at=6&paused` 查看观景台并排停留；`?scene=mountain&at=19&paused` 查看牵手上山；`?scene=stars&at=13&paused` 查看银河；`?scene=ring&at=19&paused` 等待点击开盒。纸雕版在这些参数前加 `look=paper&`。

默认按点击或滑动推进故事，每幕都会等待。每幕只需点击一次，动作完成后停留 3 秒并自动转场，下一幕重新等待。提前点击先保留完整开场，重复点击不会跳过动作；左滑/上滑（或滚轮向下、右方向键）直接进入下一幕，右滑/下滑（或滚轮向上、左方向键）返回上一幕。每次切换都从目标场景开头重新播放，字幕、动作和戒指盒一并复位。圆形提示只在等待点击或手动暂停时出现，开场、动作和自动转场期间隐藏。双指或鼠标右键拖动观察场景，单指不会再与相机拖动冲突。隐藏操作：空格暂停，暂停时点击或 Enter 只恢复播放，非暂停时 Enter 等同点击，T 字幕，M 音乐，F 全屏，Home/R 重播，End 直接进入等待开盒。录制预览可用 `?autoplay` 保留连续播放；默认模式不会越过尚未点击的新场景。
